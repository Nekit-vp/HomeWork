# Pascal Exercises

A collection of small Pascal programs covering linked lists, trees and a Turing machine exercise.

## Run an exercise

Install Free Pascal and compile one file at a time. For the linked-list example, run the following from the repository root.

```bash
fpc HomeWork.pas
./HomeWork
```

- [`HomeWork.pas`](HomeWork.pas) covers linked-list operations.
- `TreeHomeWorkNomber30.pas` contains a tree exercise.
- `turing machine.pas` contains the Turing machine exercise.
